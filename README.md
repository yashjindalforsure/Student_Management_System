# Student Management System

A simple menu-driven Student Management System built using Python. This project allows users to manage student records and store them permanently using JSON file handling.

## Features

- Add new student records
- View all student records in a formatted table
- Search students using roll number
- Calculate average marks of a student
- Validate user inputs
- Prevent duplicate roll numbers
- Store student records using JSON
- Handle missing or corrupted JSON files

## Technologies Used

- Python
- JSON
- VS Code

## How to Run

1. Install Python on your system.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```
